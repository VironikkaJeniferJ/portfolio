About Me

I'm a Full Stack Developer with 1+ years of professional experience building web applications using Angular, ASP.NET Core Web API, and relational databases. I specialize in developing responsive user interfaces, integrating RESTful APIs, and building backend functionalities that support real-world business requirements.

I enjoy solving technical problems, debugging applications, learning new technologies, and building practical software solutions. I'm always looking to improve my skills and contribute to developing reliable, maintainable, and user-friendly applications.
